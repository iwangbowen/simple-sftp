# Add and Manage Hosts

Get started with **Simple SFTP Plus** by adding your first remote server!

1. Click the **Add Host** button to configure your server's access.
2. Form-based UI or JSON definitions are supported.
3. Keep your servers organized! Create **Groups** to properly structure multiple hosts directly in the panel.

Need more options? Go to **Advanced Configuration** to set connection pooling, alive intervals, default local/remote paths, etc.
