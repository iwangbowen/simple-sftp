# Import and Export

Already have servers configured? We got you.

**Simple SFTP Plus** integrates nicely with your ecosystem:

- **Import from SSH Config**: Automatically scan your `~/.ssh/config` file and import available servers.
- **Import JSON**: Got a previous backup? Smoothly import it back.
- **Export capabilities**: Take your configuration anywhere securely. Convert and export your saved environments locally at any given time.
