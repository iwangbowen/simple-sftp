# Dual-Panel File Browser

Managing files has never been simpler! Experience our comprehensive **File Browser**.

- **Drag and Drop**: Copy files back and forth across different environments directly using drag-and-drop.
- **Side-by-side view**: Keep an eye deeply on your Workspace vs Remote filesystem simultaneously.
- **Deep search & Sync**: Supports Smart Delta Syncs preventing over-writing newly identical files locally or remotely, saving huge chunks of time.
